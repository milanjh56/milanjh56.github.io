Real-Time Driving Event Classification with BeamNG.tech

A real-time machine learning project that uses simulated accelerometer and gyroscope data from BeamNG.tech to classify driving events such as hard braking, rapid acceleration, smooth driving, and turning.

Back to projects Resume

Overview

This project explores whether lightweight machine learning models can classify driving events using only accelerometer and gyroscope data from a simulated vehicle in BeamNG.tech.

Role

I developed the simulation setup, IMU data collection pipeline, dataset structure, feature extraction workflow, and machine learning approach for real-time driving event classification.

What I built

A simulation-to-machine-learning pipeline for vehicle motion sensing.

Data collection

IMU logging system

A Python logger using BeamNGpy and the Advanced IMU sensor to continuously collect high-frequency acceleration and angular velocity data from a simulated vehicle.

Machine learning

Driving event classifier

A time-series classification pipeline designed to identify events such as smooth driving, hard braking, rapid acceleration, and turning from rolling windows of IMU data.

Technical details

The system uses BeamNG.tech with BeamNGpy to stream accelerometer and gyroscope measurements from an Advanced IMU placed near the vehicle's center console. Data is sampled at approximately 100 Hz, stored in CSV files, segmented into rolling windows, and converted into statistical features for classification with a Random Forest model.

Tools and technologies

Python, BeamNG.tech, BeamNGpy, Advanced IMU sensors, pandas, NumPy, scikit-learn, time-series processing, feature extraction, and real-time telemetry.

Process

How the sensing and machine learning pipeline was developed.

1. Simulation

Configure the vehicle and sensor

I configured a BeamNG.tech vehicle and positioned the simulated IMU near the center console to approximate where a smartphone would be mounted during real-world testing.

2. Data collection

Stream and log IMU data

I built a Python logging system that continuously records raw and smoothed three-axis acceleration and angular velocity measurements to structured CSV files.

3. Processing

Create time-series features

I segment the sensor stream into overlapping rolling windows and extract statistical features that summarize vehicle motion over short periods of time.

4. Classification

Train a lightweight model

I use a Random Forest classifier as the initial model to distinguish between driving events while keeping the system lightweight enough for future real-time inference.

Challenges

The main challenges include maintaining consistent sensor orientation, choosing useful time-window features, preventing data leakage between training and testing sessions, and making simulated IMU measurements comparable to real smartphone sensor data.

Outcome

The project has produced a working BeamNG.tech IMU logging pipeline and a foundation for training and evaluating real-time driving event classifiers. Future work will compare the simulated data with smartphone measurements collected using phyphox and expand the system to detect rough roads and potholes.
