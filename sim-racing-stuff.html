DIY Sim Racing Shifter & Handbrake

A custom USB sequential shifter and analog handbrake built around a single Arduino Pro Micro, combining 3D printing, mechanical design, calibration, and C++ firmware.

Back to projects Resume

Overview

This project was built to create a more immersive sim racing setup with a custom sequential shifter and a handbrake that behaves like a full analog control.

Role

I handled the mechanical design, fabrication, sensor integration, firmware development, and calibration workflow for the build.

What I built

A single embedded platform controlling two different inputs.

Input device

Sequential shifter

A desk-mounted 3D-printed shifter using microswitches to create a tactile sequential feel over USB.

Analog control

Handbrake assembly

A handbrake built from scrap wood, custom linkages, pivots, and a repurposed thumb joystick module to produce a usable analog axis.

Technical details

The project uses an Arduino Pro Micro (ATmega32U4) as the USB interface. Microswitch inputs handle the shifter, while the handbrake reads an analog joystick signal and converts partial travel into a full-range axis.

Tools and technologies

Arduino IDE, C++, 3D printing, basic woodworking, mechanical linkage design, microswitches, analog sensors, and calibration.

Process

How the build came together.

1. Design

Plan the mechanisms

I designed the shifter housing and the handbrake linkage so each input had a distinct mechanical feel and reliable travel.

2. Fabrication

Build the hardware

I 3D-printed the shifter enclosure and assembled the handbrake using scrap wood, pivots, and adjustable linkage pieces.

3. Integration

Wire and calibrate sensors

I integrated microswitches and a thumb joystick module, then tuned the software mapping so the analog handbrake behaved consistently.

4. Firmware

Program the USB device

I wrote Arduino firmware in C++ to read the inputs and present the hardware as a custom controller to the computer.

Challenges

The biggest challenge was getting analog travel, linkage motion, and software calibration to work together cleanly enough for a game controller.

Outcome

The result is a custom sim-racing controller that combines tactile feedback, physical fabrication, and embedded programming into one build.
